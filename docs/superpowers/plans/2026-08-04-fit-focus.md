# 핏 중심 강화 + 이전버튼 + 쇼핑링크 수정 — 구현 계획

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal (3가지):**
1. 룩북 추천을 색 중심 → **골격 맞춤 핏** 중심으로(핏 특정 아이템 + 핏 포인트).
2. 설문에 **이전 버튼** 추가(잘못 누른 문항 다시 선택).
3. 쇼핑 검색을 **구글 쇼핑**으로 변경(네이버가 외부 링크 접속을 봇으로 차단함).

**변경 파일:** `src/config/shopConfig.ts`(frameItemTerms 핏특정 + point 포함 + frameFitTip 추가, pointItemTerm 제거), `src/engine/lookBuilder.ts`(terms.point 사용), `src/components/Result/Lookbook.tsx`(핏 포인트 줄), `src/index.css`(fit-tip 스타일), 관련 테스트.

## Task 1 (원자적): 핏 특정 아이템 + 핏 포인트

- `shopConfig.ts` 교체:
```typescript
import type { FrameTypeId } from '../types';

export const shopConfig = {
  // 네이버 쇼핑은 외부 링크 접속을 봇으로 차단 → 구글 쇼핑으로 변경(외부 링크 안정적)
  searchBase: 'https://www.google.com/search?tbm=shop&q=',
};
export function shopSearchUrl(query: string): string {
  return shopConfig.searchBase + encodeURIComponent(query);
}
// 골격별 '핏 특정' 아이템 (표기 + 검색어 겸용)
export const frameItemTerms: Record<FrameTypeId, { top: string; bottom: string; point: string }> = {
  straight: { top: '베이직 셔츠', bottom: '일자 슬랙스', point: '미니멀 토트백' },
  wave: { top: '퍼프 블라우스', bottom: '부츠컷 팬츠', point: '미니 숄더백' },
  natural: { top: '오버핏 셔츠', bottom: '와이드 팬츠', point: '캔버스 백' },
};
// 골격별 핏 핵심 원리 (룩북 상단 안내)
export const frameFitTip: Record<FrameTypeId, string> = {
  straight: '군더더기 없는 I라인 정핏이 포인트 — 오버핏·과한 프릴은 피하세요.',
  wave: '허리 강조 + 하이웨이스트로 시선을 위로 — 뻣뻣하거나 헐렁한 핏은 피하세요.',
  natural: '여유로운 오버핏·와이드로 프레임을 자연스럽게 — 딱 붙는 핏은 피하세요.',
};
```

## Task 2: 설문 이전 버튼 (DiagnosePage)

**Files:** `src/pages/DiagnosePage.tsx`, (필요시) 스타일.

- DiagnosePage는 현재 `step` 인덱스(useState)로 컬러문항→사진→골격문항을 진행하며, 옵션 선택 시 자동 advance.
- **이전 버튼 추가**: `step > 0`일 때 "← 이전" 버튼 노출 → 클릭 시 `setStep(s => Math.max(0, s - 1))`. 답변은 store에 남아있어 StepCard가 이전 선택을 그대로 표시(각 질문 step의 `selected={answers[q.id] ?? null}`).
- 위치: ProgressBar 근처 또는 카드 하단(자동 advance하는 "다음"과 구분). 첫 스텝(step 0)에선 숨김.
- 사진 스텝에서도 이전 버튼 동작.
- 기존 플로우 스모크 테스트 유지(이전 버튼이 자동진행을 방해하지 않도록, 이전 버튼 텍스트는 플로우 테스트 정규식 `다음|건너뛰기|...`과 겹치지 않게 "이전"으로).
- 간단 테스트: 몇 스텝 진행 후 "이전" 클릭 시 이전 문항 텍스트가 다시 보이는지.
