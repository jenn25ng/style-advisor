# 스타일 어드바이저 — 기획 문서 (PRD)

- 작성일: 2026-07-21
- 버전: v1 초안

## 1. 배경 & 문제

퍼스널 컬러·체형 진단은 오프라인 컨설팅이 비싸고(회당 수만~십수만 원) 예약·시간 부담이 크다.
반면 온라인의 무료 테스트는 근거가 얕고 결과가 뒤죽박죽인 경우가 많아, "그래서 뭘 입지?"까지
연결되지 않는다. 사용자는 **믿을 수 있는 진단 + 실제로 옷 고를 때 쓰는 가이드**를 원한다.

## 2. 목표 (Goal)

- 무료·즉시로 **퍼스널 컬러(8타입) + 골격(3타입)** 을 진단
- 진단 결과를 **어울리는 색 팔레트 + 실전 코디 가이드**로 연결
- "전문가가 봐준 것 같다"는 신뢰감 — 규칙과 근거가 분명한 진단

### 비목표 (Non-goal, v1)
- 사진만으로 자동 확정 진단 / 쇼핑·구매 연동 / 커뮤니티 / 계정 기반 히스토리

## 3. 타깃 사용자

- 퍼스널 컬러/체형을 **처음 알아보는** 20~40대
- 옷은 있는데 **조합·색 선택에서 늘 헤매는** 사람
- 오프라인 컨설팅 전에 **가볍게 먼저 확인**하고 싶은 사람
- (자세한 페르소나는 `페르소나.md`)

## 4. 핵심 가치 제안

> "5분 설문으로, 나에게 어울리는 색과 코디 규칙을 전문가 기준으로 알려준다."

- **신뢰:** 확립된 이론 기반 규칙 + "왜 이 타입인지" 근거 제시
- **실전성:** 색 이름/HEX 팔레트 + 상·하의 핏·소재·실루엣 가이드
- **간편:** 설치·로그인 없이 즉시, 결과는 내 브라우저에 저장

## 5. 기능 범위

### v1 (필수)
1. 퍼스널 컬러 자가진단 설문 (5~6문항)
2. 골격 자가진단 설문 (5~6문항)
3. (선택) 사진 색 참고 — 웜/쿨 힌트 보조
4. 결과 페이지: 타입 요약 + 근거, 베스트/워스트 색 팔레트, 24조합 스타일 가이드
5. 결과 localStorage 저장 / 다시 진단
6. 모바일 우선 반응형

### v1.5~추후
- 세부타입 일러스트 룩북, 내 옷장 등록·조합 추천, 결과 공유 이미지, 계정 동기화

## 6. 사용자 흐름 (요약)

시작 → 컬러 설문 → (사진 참고) → 골격 설문 → 결과(팔레트+가이드) → 저장/재진단

## 7. 성공 기준 (v1)

- 설문 완료율: 진단 시작 대비 **70%+** 결과 도달
- 결과 유용성: 결과 페이지 스타일 가이드가 **타입별로 빈 값 없이** 제공
- 신뢰성: 진단 규칙이 문서화된 지식베이스(`docs/knowledge/`)에 근거
- 접근성: 모바일에서 한 손 조작 가능, 색 대비 준수

## 8. 리스크 & 대응

| 리스크 | 대응 |
|---|---|
| 자가진단 정확도 한계 | 근거 표시 + "참고용" 안내, 사진 힌트로 보조 |
| 콘텐츠 신뢰도 | 지식베이스 리서치 선행, 출처 문서화 |
| 24조합 콘텐츠 물량 | 규칙 합성 + 강조 조합만 개별 문구 |
| 사진 프라이버시 | 전부 클라이언트 처리, 서버 업로드 없음 |
